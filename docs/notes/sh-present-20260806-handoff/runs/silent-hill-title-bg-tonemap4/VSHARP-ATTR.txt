## Why the table holds that V#

UE NGG mesh attribute path (ES `800d69`):
1. Userdata s8 holds a float4 constant V# (scale/bias), not the mesh VB.
2. Shader S_LOADs V# from heap (draw 34299: `80d0351584`) with dynamic offset
   masked to `0x1F0`.
3. Heap slot 0 is RegularBuffer → base `7120e7d8c0`, stride 32, records 6,
   word3 `0x00005204`.
4. Meshlet supplies FORMAT/swizzle override:
   s20=0x26e0 → format 77 (float4) pos
   s21=0x42020 → format 64 (float2) UV, soff 16
5. Shader patches word3 before BufferLoadFormat; format==0 keeps heap word3.
   DST_SEL immediates after load: `s14=0x022C0204`, `s15=0x0FAC03AC`
   → slot1 = XY01 (UV), slot3 = XYZW (pos).
