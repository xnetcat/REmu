## Why the table holds that V#

UE NGG mesh attribute path (ES `800d69`):
1. Userdata s8 holds a float4 constant V# (scale/bias), not the mesh VB.
2. Shader S_LOADs V# from heap `8054eb9354` (draw 47402 TARGET globals).
3. Heap slot 0 is RegularBuffer → base `7120e7d8c0`, stride 32, records 6.
4. Meshlet at s14 (`72a0e11600`) supplies FORMAT/swizzle override:
   s20=0x26e0 → format 77 (float4) pos, slot 0, soff 0
   s21=0x42020 → format 64 (float2) UV, slot 0, soff 16
5. Shader patches word3 before BufferLoadFormat; format==0 keeps heap word3.

So the RegularBuffer in the table is architecturally correct, not stale mis-decode.
